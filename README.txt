SMART MEDICINE REMINDER & EXPIRY TRACKER - EXTENDED DESKTOP VERSION

Technology: Python Tkinter + SQLite
Server: NOT required

NEW FEATURES
1. Email registration and login
2. Medicine add/edit/delete with category, doctor, batch number and instructions
3. Multiple reminder times per medicine (example: 08:00, 14:00, 20:00)
4. Automatic popup reminder at scheduled times
5. Taken / Missed dose tracking
6. Quantity automatically decreases after a Taken dose
7. Refill stock feature
8. Custom low-stock threshold
9. Expired and expiry-within-30-days warnings
10. Medicine search
11. Dose history page
12. Export dose history to CSV
13. Adherence analytics
14. Local SQLite database backup
15. Data folder shortcut
16. Desktop shortcut creator

HOW TO RUN
A. Easiest way:
   Double-click RUN_Smart_Medicine_Reminder.bat

B. VS Code:
   Open this folder in VS Code.
   Open Terminal.
   Run: python Smart_Medicine_Reminder.pyw

DESKTOP SHORTCUT
1. Double-click CREATE_DESKTOP_SHORTCUT.bat.
2. A shortcut named Smart Medicine Reminder will be created on the Desktop.
3. Double-click it to open the application.

IMPORTANT
- Keep the data folder beside the Python file.
- Existing databases from the previous version are automatically upgraded.
- No Flask, browser, localhost or web server is used.
- The application is for project/demo tracking and is not a substitute for medical advice.
